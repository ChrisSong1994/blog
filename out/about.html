关于我

你好 👋

这是一个用 Next.js 搭建的静态博客，文章可以从 GitHub Issues 自动同步过来。

这个页面是「关于我」的模板，直接改 posts/about.mdx 就行 —— 支持完整的 MDX 语法， 可以写 Markdown，也可以直接写 JSX。

关于这个站点

  • 首页、博客列表、项目、关于我，全部由 src/config/site.ts 一处配置驱动
  • 文章支持标签、封面、阅读时长、目录（TOC）、代码高亮与图片点击放大
  • 在 GitHub 上新建一个 Issue，Actions 就会把它同步成一篇 .mdx 自动发布

联系我

把下面的链接换成你自己的即可：

  • GitHub：github.com/your-github-name
  • 邮箱：you@example.com

也可以直接编辑 src/config/site.ts 里的 social 数组，首页的社交图标会跟着变。
